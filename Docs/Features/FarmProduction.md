# 농장 건설과 식량 생산

상태: 구현·씬 연결·Unity 검증 완료.
브랜치 `codex/farm-production`, 기준 main `5e3354a`.

## 구현한 규칙

- 준비 단계에 BUILD FARM → 땅 클릭으로 1.8×1.8 크기의 농장을 배치합니다. 기본 목재 30을 지불하고 기존 건설 격자·영지 경계·충돌 검사를 재사용합니다.
- 농장마다 준비 시간 8초에 식량 4를 생산합니다. 식량 초기값 0, 저장 상한 200입니다. 정지·침공·격퇴 결과·비활성화에서는 남은 시간을 보관합니다. 오프라인 시간이나 지나간 침공 시간을 소급 생산하지 않습니다.
- 창고에 한 번의 수확을 모두 넣을 공간이 없으면 수확을 대기합니다. 공간이 생기면 대기한 한 번의 수확을 전달하고 다음 주기를 시작합니다.
- 농장은 기존 구조물 체력 60·적 공격·길찾기 장애물·수리·철거 규칙을 사용합니다. 구매 목재 30을 기준으로 손상 비례 수리 비용과 환급을 계산합니다. 전투 파괴는 환급 없이 생산을 중단합니다.
- BUILD WALL, BUILD FARM, SET RALLY 중 한 도구만 지도 클릭을 사용합니다. 우클릭/Esc/일시정지/침공 시작 시 배치를 취소합니다. 농장 HUD 클릭은 유닛 선택·명령에 전달하지 않습니다.
- 다음 침공까지 건물·식량을 유지하고 RESTART는 초기화합니다.
- 농장 수는 비용·배치 공간으로 제한됩니다. 현재 식량 소비·노동자 배치·저장은 다음 기능에 연결할 항목입니다. 식량만 생산하는 상태를 완성된 영지 경제로 간주하지 않습니다.

## 코드 구성

- `EstateStockpile`: 목재 API 유지, 식량·저장 상한·추가/소비 검증. 성공한 자원 변경만 알림.
- `FarmSettings`: 건설 비용·수확 시간·생산량. 런타임 상태를 공용 에셋에 저장하지 않음.
- `FarmProduction`: 농장별 남은 시간과 수확. 주변/씬 검색 없음, 수확 성공 시만 창고 알림. 알림 전에 다음 수확 시간을 확정.
- `WallConstruction`: 기존 배치 검사·거래·체력 초기화 공통 경로에 농장 프리팹 추가. 농장 설정이 없는 이전 씬은 방어벽 기능 유지.
- `WallStructure`, `WallHealthView`: 기존 피해·파괴·체력 표시 재사용. 클래스 이름은 기존 참조 호환을 위해 유지. 배치 도구가 대상의 실제 크기로 수리·철거 미리보기를 표시.
- `FarmHUD`: 창고·건설·도구 변경 알림과 준비 가능 여부가 바뀔 때 표시 갱신.
- `FarmSetup`: Unity API로 설정 에셋·농장 프리팹·HUD·씬 참조를 구성. BasicCombat 저장/Play 중지 검사, 중복 추가 방지.

## 사용법과 설정

Unity 상단 **Project F → Open Gameplay → Play**에서 오른쪽 **BUILD FARM**을 누르고 빈 땅을 클릭합니다. 초록색은 건설 가능, 빨간색은 다른 물체·영지 경계·목재 부족으로 건설할 수 없는 위치입니다. 기존 병사와도 겹쳐 지을 수 없습니다. 우클릭 또는 Esc로 배치를 종료합니다.

준비 단계에서 8초를 기다리면 FOOD가 4 증가합니다. REMOVE BUILDING과 REPAIR BUILDING은 방어벽·농장 모두에 적용합니다. 기본 수확 주기·생산량·건설 비용은 **Project F → Select Farm Settings**에서 조절합니다. 식량 상한과 초기값은 씬의 EstateStockpile에서 조절합니다.
