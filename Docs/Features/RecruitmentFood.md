# 병력 충원 식량 비용

상태: 구현·Unity 실행 검증 완료. 브랜치 `codex/recruitment-food`, 기준 main `aca5870`.

## 플레이 규칙

- 병사 1명 훈련에 목재 20과 식량 4를 함께 지불합니다. 한 자원이라도 부족하면 아무것도 차감하지 않습니다. 초기 식량은 0이며, 농장 1회의 수확으로 병사 1명의 식량을 확보합니다.
- 훈련 시간 5초·생존 병력 상한·집결·출구 대기·침공과 일시정지 규칙은 기존 기능을 유지합니다.
- `TRAIN SOLDIER` 옆에서 비용과 부족한 자원을 확인합니다. `W`는 목재, `F`는 식량입니다. 훈련 중에는 환불량이 표시되며 `CANCEL / REFUND`로 최초 지불한 두 자원을 전액 돌려받습니다.
- 지불한 식량만큼 창고 공간을 환불용으로 보관합니다. 예: 식량 200에서 훈련하면 사용 가능 식량 196, 환불용 공간 4입니다. 농장 수확은 그 공간을 사용하지 않습니다. 취소하면 식량 200으로 돌아오고, 병사 배치가 끝나면 공간을 풀어 대기하던 수확을 받습니다.
- 식량 비용은 구매 당시 값으로 확정합니다. 설정을 바꿔도 진행 중인 훈련의 환불량은 변하지 않습니다. 비용 0인 설정도 지원합니다.
- RESTART는 식량·훈련·환불 공간을 초기화합니다. 정지·비활성화·침공 중에는 지불 상태를 유지하고 다시 차감하지 않습니다.

## 유지보수

`RecruitmentSettings`가 가격, `UnitRecruitment`가 훈련 슬롯, `EstateStockpile`이 두 자원의 원자적 거래와 환불 공간을 소유합니다. 내부 영수증은 최초 지불 금액·발행 창고·정산 여부를 보관하므로 중복 환불과 다른 창고의 정산을 막습니다. 자원·슬롯 상태를 모두 확정한 뒤 변경 알림을 보냅니다. 훈련 완료 또는 소유 훈련소 제거 시 예약 공간을 해제합니다.

훈련 구매당 영수증 하나를 만들며 매 프레임 거래 객체나 씬 검색을 만들지 않습니다. HUD는 기존 변경 알림과 시간 표시 갱신을 사용합니다. 생산·모집 숫자는 공용 설정 에셋에 저장하고 런타임 자원과 환불 상태는 씬 인스턴스에 둡니다.

## 검증 범위

추가 PlayMode 15개: 식량/목재 각각 부족, 농장 수확→병사 실제 배치, 창고 포화 환불, 배치 후 수확 재개, 이벤트 중 재진입/중복 구매·환불 차단, 구매 후 가격 변경, 정지·비활성화, 침공 보관과 재개, 실제 HUD 클릭, 씬 재시작, 식량 비용 0, 다른 식량 소비와 환불 공간의 공존, 배치 알림 전에 병력 상한 반영, 병력 등록 알림에서 배치 중인 훈련의 취소·재구매 차단.

기존 충원 사용 검사에는 식량을 명시적으로 공급해 해당 검사의 원래 목적(이동·선택·집결·숙련도 등)을 유지합니다. 새 검사는 초기 식량 0과 실제 농장 생산 경로를 확인합니다.

병력의 주기적 식량 유지비, 주민 소비, 보급로·원정 수송은 아직 구현하지 않았습니다. 이 기능은 농장과 병력 모집을 연결하는 단계입니다.
