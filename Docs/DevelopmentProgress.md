# Project F 개발 진행

## 진행 원칙

기능 하나 선정 → 구현 → Unity 검증 → 사용법 안내 → 사용자 최종 확인 → 다음 기능.
사용자 확인 전에는 다음 기능 개발이나 main 병합을 진행하지 않습니다.
수정 요청은 현재 기능 브랜치에서 처리합니다.
