# Project F 완성 계획

기준: 원본 `GameConcept.md` 1~48장. 2026-11-19 사용자가 게임 완성까지 연속 개발·자동 병합·필요한 2D 이미지 제작을 허용했습니다. 이전 기능별 승인 대기는 해제되었습니다.

## 완료 기준

새 캠페인부터 몬스터 왕 격파와 엔딩까지 실제 플레이로 연결되어야 합니다. 아래 시스템이 서로 영향을 주고, 저장·불러오기·설정·한국어 UI·배포 빌드가 동작해야 합니다. 기능별 검사와 실제 플레이, 목표 병력 규모의 성능 측정을 통과해야 합니다. 현재 3차 방어 프로토타입은 완성 게임이 아닙니다.
